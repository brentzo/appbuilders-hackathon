# Yumi for iPhone

The iPhone app, planned for after Android works end to end (priority p2).

Status: empty scaffold, not started. No objectives yet.

## What it will be

iOS does not let apps control other apps.
So the iPhone is a voice remote for the Mac plus a small set of phone tools, not a second full companion.

- Speak a goal in the app. It is transcribed on the device (forced on-device, never cloud) and sent to the Mac.
- Offer the tools iOS allows our app: location, photos the user picks, calendar, contacts, and alarms through AlarmKit or a Shortcut.
- Receive commands from the Mac through push notifications. The user may need to open the app to run them.

## Initial technical plan

- Swift with SwiftUI.
- Shares the Swift types generated by [protocol](../protocol/README.md) with the [mac](../mac/README.md) app.
- Needs the [bridge](../bridge/README.md) to send push notifications through Apple's push service to wake the app.
