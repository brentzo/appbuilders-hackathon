# Yumi logo and app icons

Background-free logo and icon files for the apps and the stores.
The cat's cursor states are not here: they live in the Rive file (`character/yumi-cat.riv`, [OBJ-10](../../objectives/OBJ-10-yumi-cat-v0.md)).
Everything here is generated by `character/remotion/scripts/export-assets.ts`, so do not edit these files by hand.

## Logo

| File | Use it for |
|---|---|
| `logo/yumi-mark.svg`, `logo/yumi-mark-{256,512,1024}.png` | The full-color mark, on any light background |
| `logo/yumi-mark-mono.svg` + 512 PNG | One color in cocoa, for single-ink uses |
| `logo/yumi-mark-white.svg` + 512 PNG | One color in white, for dark or photo backgrounds |
| `logo/littermates/yumi-{mint,sky,slate}.svg` + 512 PNGs | The ghost littermates, for docs and the demo |

## macOS

| File | Use it for |
|---|---|
| `icons/macos/yumi-appicon.svg`, `appicon-{16..1024}.png` | The app icon. The PNG sizes fill an Xcode `AppIcon` set (16, 32, 64, 128, 256, 512, 1024) |
| `icons/macos/yumi-menubar.svg`, `menubar-18.png`, `menubar-36.png` | The menu bar item. Black on transparent: set it as a template image so macOS tints it |

## Android

| File | Use it for |
|---|---|
| `icons/android/ic_launcher_foreground.svg`, `ic_launcher_background.svg` | The adaptive icon layers. Import each in Android Studio as a Vector Asset |
| `icons/android/mipmap-{density}/ic_launcher.png`, `ic_launcher_round.png` | Legacy launcher icons for every density |
| `icons/android/playstore-512.png` | The Play Store listing icon. It is full bleed, because Google Play applies its own mask |

The adaptive background and the Play Store icon are opaque by design.
Every other file is transparent outside its own shape.

`manifest.json` lists every file and size.

## Regenerating

```bash
cd character/remotion
npm install
npm run export:assets
```
