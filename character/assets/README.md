# Yumi app assets

Background-free stand-ins of the Yumi cat for the Mac and Android apps, one set per cursor state.
Use them until `character/yumi-cat.riv` exists ([OBJ-10](../../objectives/OBJ-10-yumi-cat-v0.md)), then switch to the Rive file.
Everything here is generated by `character/remotion/scripts/export-assets.ts`, so do not edit these files by hand.

## Files

State names match the protocol's `CursorState` values: `idle`, `listening`, `thinking`, `moving`, `acting`, `waitingForUser`, `paused`, `done`, `stuck`.

| Path | Format | Use it for |
|---|---|---|
| `svg/yumi-{state}.svg` | 512 px vector, transparent | Static images that must stay sharp at any size. Import into an Xcode asset catalog, or convert to a VectorDrawable in Android Studio |
| `png/yumi-{state}@{1,2,3}x.png` | 256, 512, 768 px, transparent | Static images where a bitmap is simpler, such as notifications or list rows |
| `video/yumi-{state}.webm` | 512 px, 30 fps, 4 s, VP9 with alpha | Animated stand-ins. Each loop is seamless: the last frame flows into the first. Includes the small state marks (sound arcs, think dots, z's, question mark, sparkles) |
| `manifest.json` | JSON | Sizes, file patterns, and the hotspot for each format |

## The hotspot

The cat's paws are the click point (SPEC-04 requirement 13).
`manifest.json` gives the paw coordinate for each format, so an app can place the image with the paws exactly on the target.

## Regenerating

```bash
cd character/remotion
npm install
npm run export:assets
```
